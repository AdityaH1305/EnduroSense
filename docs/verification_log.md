### Checked and confirmed correct (no change needed)

- **Causality:** every Model A feature uses only past data (real-data perturbation test); sequence windows use completed bins only.
- **No test-set access outside the `final=True` gate:** the only caller is that gate's own unit test, which counts rows of the flights table.
- **Everything fitted after the split uses dev data only:** the discharge curve, recovery, imputers, scalers, baselines, NN early-stopping set and hyperparameter choice. The Phase 1 rest-voltage estimate and recovery constant are fitted on all flights because chains, and therefore the split, are built from them; this is documented.
- **Determinism:**
  - Rebuilding Phases 0–2 gives byte-identical tables (content hashes of all 7 tables).
  - The split rebuilds to the same hash.
  - Training the same GRU twice gives identical predictions.
  - The full Phase 3 re-run reproduces every CV number.
- **Label maths:** remaining energy + energy drawn is constant within every chain; curve interpolation and extrapolation are checked against synthetic cases.
- **Model B accounting:** parts add up to each flight's total to within 10⁻¹⁴ Wh.
- **Documented numbers** (chains 90/71/190/60/43, label coverage, CV table) match the regenerated outputs.
